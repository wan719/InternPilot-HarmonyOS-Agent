# InternPilot 鸿蒙求职 Agent 产品简报

## 作品名称

InternPilot 鸿蒙求职 Agent

## 一句话定位

面向高校学生的鸿蒙端求职准备助手，把岗位信息、简历匹配、行动建议和提醒串成一个轻量闭环。

## 目标用户

- 正在找实习、校招或科研助理机会的高校学生。
- 需要快速判断岗位是否适合自己的学生。
- 想把求职任务拆成可执行计划，但不想维护复杂表格的人。

## 核心痛点

- 岗位描述长，学生很难快速判断自己是否匹配。
- 简历和岗位之间的差距不清楚，不知道先补哪一块。
- 投递、笔试、面试准备容易遗忘。
- 求职资料分散在聊天、网页、文档和截图里，缺少统一入口。

## 核心闭环

1. 用户输入或粘贴岗位信息。
2. 用户补充自己的简历摘要、技能关键词或经历片段。
3. 系统调用后端轻接口进行分析。
4. AI 返回匹配度、风险点、建议行动和提醒时间。
5. 鸿蒙客户端展示分析结果，并创建本地提醒。

## 初赛 MVP 功能

- 岗位信息输入：支持手动粘贴岗位 JD。
- 个人背景输入：支持填写技能、经历、目标岗位。
- AI 分析结果页：展示匹配分、优势、短板、行动建议。
- 求职提醒：根据返回结果创建本地提醒或 mock 通知。
- fallback mock：没有后端或 AI 服务时，使用固定 JSON 完成演示。

## 不做范围

- 不接入真实招聘平台账号。
- 不抓取招聘网站数据。
- 不做完整用户系统。
- 不保存真实身份证、手机号、邮箱密码等敏感信息。
- 不承诺比赛规则、评分细则或官方流程。
- 不做复杂多 Agent 编排。

## 技术架构草案

- HarmonyOS 客户端：ArkTS 页面、表单输入、结果展示、通知提醒。
- 后端轻接口：提供 `POST /api/c4/analyze`，接收岗位和用户背景。
- AI 分析层：把输入整理成结构化 JSON，返回给客户端。
- Mock 层：本地或后端内置固定响应，保证演示不断链。
